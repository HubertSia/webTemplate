# Usage of TimTools
Hello! If you're reading this, you're currently using a web template that includes a gulp.js setup with TimTools.
TimTools should be helpful for future web development projects (like a portfolio or a full-scale commercial website).

# How does it work?
For those who have used the terminal or Git Bash before, this should be straightforward. If you haven’t, make sure you install Node.js on your machine—this is required for npm and will allow you to run the gulp.js setup.

Once Node.js is installed, follow these steps:

1. In the VS Code terminal, type ```npm i```. This will install the necessary files from the **package.json**.
2. Once the installation is complete, type ```npm start``` in the terminal. This will generate the **dist** folder. Think of it as the equivalent of VS Code’s “Go Live.” It’s also what you’ll use if you want to deploy your project online (e.g., on GitHub or a server).
3. TimTools includes many features you can use, feel free to explore and experiment. If you have any questions, let me know :D

# Other useful tips
- This template uses SCSS for styling. It retains CSS functionality while adding useful features, such as creating your own reusable style structure (see **main.scss** and the **components folder**).
- The template uses JavaScript. All JS files are handled through **ComponentFactory.js**, which is then processed into **main.js** as the global script for all HTML files. Feel free to explore these files (**main.js, ComponentFactory.js, and the component** folder).
- There is a **_partials** folder that contains **_header** and **_footer**, which you can customize to fit your needs.
- It is compatible with **PHP**, meaning you can use it as a custom theme for WordPress if needed (you may want to look up a guide—I don’t fully remember the setup).
