# Usage of the timTools
Hello, if you're reading this. You're currently using a template web that has a glup.js folder that has TimTools.

The TimTools should be helpful for any future Web developpement projects (Like Portfolio or full on market website)


# How does it work?
For those who utilize the terminal/Gitbash before, it should straighfoward. For those who don't, make sure node.js is installed on your machine for the npm system, it will installed the gulp.js folder.

Once you got node.js installed do the following

1. On VScode terminal, type in npm i This will install the necessary folder from the json file

2. Once the download is completed, type in npm start on the terminal. This will download the dist folder. Think of it as you're "Go Live" equivalant of VScode. It is also what you're going to use to upload if you ever want to upload online on the github or on a server.

3. TimTools has a lot of features that you can utilize, you're free to explore and expirement however you wish. If you got any question, let me know

# Other usfull tips

- The template utilize SCSS files as it style sheet. It retains the some feature of CSS but it has some helpful feature of creating your own sudo-library of style sheets (refer to mainn.scss and the components folder)
- The template utilize JS, although all JS type file will be ruinning in the CompoenetFactory.js wich then be process to Main.js to be the universal javascript to all the HTML. You are free to browse it (refer Main.js, ComponentFactory.js and the comopent folder)
- There's a _partial folder that contains _header and _footer. You can use it to style in you're own need

- It is compatible with PHP, that means you can use it as a custom them for Wordpress if you ever want to use it (please look up online about it, i forogt how to use it)
